InsightForge Architecture

A research brief goes in and a cited intelligence report comes out. The control plane is designed first: one LangGraph orchestrator owns every stage and limit, every boundary has a guardrail, and every failure ends in a defined outcome.

  • LLMs via OpenRouter
  • Embeddings: FastEmbed bge-small, local
  • LangGraph + deepagents
  • FastAPI · Next.js 14
  • Postgres · Redis · Qdrant

System, in four layers

request / response safety and human approval state and ingestion 03a–03d one guardrail layer, reused at four boundaries SubTask[] typed state passed between agents
